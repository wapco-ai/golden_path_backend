These tiny, synthetic media fixtures exercise real server MIME detection and
multipart uploads. Photos are generated solid-color 2×2 images. `tiny.mp4` is a
16×16 H.264 color clip created with FFmpeg. `tiny.wav` is PCM silence and
`tiny.pdf` is a minimal test PDF. Tests pad temporary copies for exact size
boundaries; fixture originals are never modified. No external service is used.
